How to read this

Every label cites evidence. Unread means an agent's own session log, the repository ledger or a commit marker says an agent wrote the line, and nothing shows a person looked at it.

Seen means a person approved the diff in a prompt, changed it, reviewed it, or marked it read. It does not mean understood.

A line with no evidence either way counts as human, so the unread figure is a lower bound.
